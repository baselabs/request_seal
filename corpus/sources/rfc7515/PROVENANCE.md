# Source provenance

Published test material extracted from [RFC 7515](https://www.rfc-editor.org/rfc/rfc7515.txt), A. Promoted from existing fixtures without byte changes. Test keys are never operational credentials.

`upstream-SHA256SUMS` files are historical copies from the original fixture
layout and are not checkable in place. The local `SHA256SUMS` and corpus index
verify this directory layout.
